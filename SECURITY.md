# Security Policy

## Supported versions

The latest release (currently 0.1.0) and the default branch (`main`) are
supported with security fixes.

## Reporting a vulnerability

Please report suspected security issues privately. Do not open a public issue.

- Email [contact@speedle.io](mailto:contact@speedle.io) with `SECURITY` in the
  subject.
- When GitHub private vulnerability reporting is enabled for this repository,
  you can also use the **Report a vulnerability** button on the repository's
  Security tab.

Please include:

- the affected version or commit;
- the component or endpoint involved;
- steps to reproduce the issue, or a proof of concept;
- the potential impact;
- any mitigation you have identified.

We aim to acknowledge new reports within 5 business days.
